# Gold Digger - Gold Price Trending Dashboard

A real-time dashboard displaying gold price trends over the last 30 days.

## Features

- Real-time gold price visualization
- 30-day price trending chart
- Interactive chart with tooltips
- Responsive design

## Tech Stack

- React 18
- TypeScript
- Vite
- Recharts (for data visualization)
- Axios (for API calls)

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Visit `http://localhost:3000` to view the dashboard.

### Build

```bash
npm run build
```

## Data Source

The dashboard fetches gold price data from a public API, displaying the last 30 days of price trends.
